# ybj-contrast

把作者已经写出的文字变得更值得继续读，同时让作者读起来仍然觉得「这是我说的话」。适用于文章、销售信、社交帖和口播稿的开头、结尾，也适用于用户指定的一段正文。目标是提高继续阅读的意愿；不承诺留存、成交或流量结果。

方法来自用户提供的 Callum 与 Kane 对话：从有效故事中提取可复用的结构，而不复制别人的个人手感。将「然后发生 B」检查为「A 遇到什么变化，才使 B 值得讲」。这段对话是方法启发，不是效果证据，也不意味着某套课程的官方方法。

## 改稿边界

- 先保真、再保口吻，最后增强吸引力。保留事实、观点、立场、情绪强度、叙述人称以及「可能」「有时」等限定。
- 原文是风格依据。观察常用词、长短句、停顿、口语程度、幽默与克制程度；保留有辨识度的措辞和自然的不工整。不要统一改成广告腔、金句体或整齐排比。
- 优先移动原句、删除重复、拆句和补足必要衔接。只有这些不足以表达已有关系时才改写措辞；不为显示工作量而重写。
- 不添加未经提供的数字、经历、心理活动、对话、客户反馈、成绩、权威背书、稀缺性或因果解释。原文只有时间先后，不能擅自改成因果。
- 反差应来自原文可支持的差异，不把温和差异改成对立，不扩大为「所有人都错了」。不默认套用「你以为……其实……」「99% 的人不知道」等句式。
- 不把留住读者等同于吊胃口。可以直接给结论，再让读者想知道为什么、如何做到或有什么代价。开头承诺必须能在所给正文中兑现；正文未提供时，不承诺其中存在某个秘密、方法或结果。

## 工作方式

### 1. 确定改哪里

用户给一段，就改这一段；给全文且要求改开头，就只改开头，并读后文确认衔接和兑现；要求改结尾，就读必要的正文后只改收尾；要求改首尾，就分别处理开头与结尾。明确要求通篇处理时才扩展范围。不要因为文字短就拒绝。

已有原稿就直接做。没有原稿时，请用户贴来要改的文字。平台、受众、长度优先沿用上下文；只有缺失信息会实质改变改法时才追问，不要求用户先填问卷。

### 2. 先选对比对象，再处理连接词

这项能力有两层：用转折表达对比，以及选出值得对比的两个东西。优先花精力在第二层，不要找到第一组反差就开始润色。

内部完成一轮配对筛选，通常不必向用户展示清单：

1. **列有意思的事实**：从原稿和用户已给的上下文中提取具体结果、做法、限制、成本、经历或细节。每项都要有出处；素材少就少列，不为了数量编造。
2. **找基线预期**：针对每项事实，判断目标读者在不了解这件事时可能预期什么。区分原文明确写出的预期、上下文支持的合理推测，以及无法判断的预期。合理推测只是内部候选，不能直接写成「大家都认为」；无法判断且决定改法时，向用户问一个具体问题。
3. **逐一配对**：把每个事实 B 与针对同一对象、同一维度的预期 A 配对，例如预期投入与实际投入、预期结果与实际结果。不得通过偷换人群、时间范围、比较标准或遗漏条件放大距离。也可使用原稿明确存在的目标与现实、前后变化，但不要将个人预期冒充大众预期。
4. **比较距离**：问「读者如果原本预期 A，看到 B 会需要多大程度地更新判断？」比较各对的意外程度，不用字面反义、夸张程度或虚构分数代替。先排除缺乏依据、与主旨无关、正文无法解释的候选，再从剩余配对中选距离最大的一对；接近时优先选择更贴近目标读者、也更少改动原话的一对。
5. **确认推进方向**：这组差异会自然引出什么问题、行动或结果？下一句应承接它，正文应能回应它。最惊人的细节如果把读者引向偏题的期待，就不是适合这个开头的选择。

如要向用户解释选择，用具体措辞描述「原本会预期什么 → 实际是什么」，并注明未确认的预期。不要把内部假设包装成事实。

只选一个主要差异，不把所有句子都做成反转。如果没有真实反差，就通过具体信息前置、删铺垫或明确问题提升可读性，并说明现有材料不足以支持更强反差。需要补素材时指出缺少什么，不代填故事。

### 3. 开头：让读者马上知道发生了什么、为什么值得看

仅在处理开头或整篇时应用。先完成前面的对比对象选择，再把它变成开场。优先让第一句就带出具体对象、事件或变化；不要把「第一个词必须讲语境」理解为破坏自然语序的硬规定。避免只说「我发现一个特别酷的东西」「今天这件事太震撼了」却不交代到底是什么。神秘感、情绪与氛围不能替代理解，原稿有作用的叙事氛围可以保留。

**短视频的优先顺序：语境 → 熟悉的预期 → 反差。**

- 语境：在讲谁、什么事或什么结果？让目标观众迅速认出与自己的关系。
- 熟悉的预期（「靠」）：接到观众已有的经验、做法、成本或判断上，让他知道比较基线是什么。依据前面的基线筛选，不冒充大众共识。
- 反差：给出与该基线不同的真实事实或结果。可用「但」或有依据的「因此」衔接，也可以直接并置。所谓反共识，应体现对预期的更新，不是为反对而反对。

组件可以压在一句中，不要求每项各写一句。先确保清楚，再决定是否需要更多铺垫。短视频重点检查前 5—10 秒能否建立语境和继续看的理由；这是工作参考，不是适用于所有文体的硬时长。

**长视频或需要较长投入的解说：语境 → 痛点与利害关系 → 基线与反差 → 证明 → 计划。**

- 利害关系：这个具体问题为什么对这类读者重要？原稿里有何成本、障碍、机会或后果？不虚构焦虑。
- 证明：为什么值得相信作者这次的讲解？优先使用原稿已有的相关实践、可展示结果、案例或资历；没有粉丝数也可以建立可信度。不要为了凑公式编成绩，也不要用无关头衔代替证据。
- 计划：接下来具体会讲什么、怎样帮助读者理解或行动？必须与现有正文对应，不凭空承诺「八个步骤」或补出不存在的方法。

这是长解说的优先组织顺序，可合并重复功能，避免开场拖长；不要因文章篇幅长就强塞资历和目录，尤其是个人随笔。读者已知道的信息不必再讲一遍。对话中对「5P」归属的回忆并不确定，不将这套方法标成已核实的某位作者原版公式。

**把开头的时间花在选择和验证上。** 对初学者，若用户询问时间安排，可将「两小时中约一小时打磨开头」作为讲述者的练习建议：先找素材和基线，比较几组不同的对比对象与信息顺序，再压缩无效铺垫，朗读检查是否一听就懂、是否能接正文。不要把时间都花在同一句的同义词替换上。当语境清晰、反差可信、正文能兑现且口吻自然后就停止反复打磨，转向正文与结尾。这不是要求模型等待一小时，也不是固定预算；对话中的 50%、95%、100% 不作为通用效果数据。

教学例：只有在素材确实提供且比较条件一致时，才可以写「以前做一张这样的海报要两小时，但这个 AI 工具 60 秒就做完了」。这里有效的是具体任务、熟悉成本与实际结果之间的关系；数字是对话示例，不能挪作用户的实测。单说「这个工具会改变设计师的一切」仍然太泛，不能代替具体变化。

### 4. 调整句子之间的关系

把「但 / 因此」当作关系检查，不是必填词：

- **但**：前一句建立了方向或预期，后一句出现原稿确实存在的阻力、限制或意外。
- **因此**：前一个事实推动了后面的选择或结果；只有原文支持这一关系才这样连接。
- **然后**：必要的时间顺序可以保留。问题在于只罗列事件却没有阅读理由，不在于用了这个词。

按原稿需要选择动作：把已有的异常或关键结果提前；缩短预期与实际之间的距离；让目标、阻力、行动、结果接得更清楚；删除重复解释；把下一句接到当前句自然引出的问题上。不要求凑齐一套结构。

反差大小来自信息关系，不来自「竟然」「震惊」「万万没想到」的数量。衔接可以是换行、停顿或并置，不一定显式写连接词。个人感受、随笔和说明文字也不必强行改成故事。

### 5. 结尾：先明确观点，再选择收尾方式

仅在处理结尾或整篇时应用。先从原稿找出作者最终想留下的观点：这件事为什么重要，作者怎么看？以「发生了什么 → 对它的拆解 → 为什么重要的观点」检查承接，尤其适合解说视频；这是理解内容的线索，不要求把随笔或其他文体强改成三段式。结尾紧接这一观点，不另起无关议题，也不替作者发明立场。

**让价值延续到最后一秒。** 读者已经把注意力交给了这篇内容，结尾应给他们值得带走的东西：一个新的好奇点、一次娱乐或情绪上的满足，或一个有用的理解与判断。无需同时具备三种价值，也不必再塞入新知识。避免正文一结束就用重复总结、套话或索取互动耗尽余味；一个已经落定的自然收尾也有价值。

最后留下的感受应能让读者自发觉得值得分享、讨论或继续关注作者。把这些行为视为价值可能引出的结果，不以命令转发、刻意争议或诱导评论替代价值。讲述者提到的「30% 看到最后」及开放循环表现最好的经验属于其叙述语境，不作为通用完播率、效果保证或固定选法。

结尾还要回应读者为什么来读这位作者。若原稿定位是科技、AI 或商业战略解说，先确保已把事件拆解清楚，再把最后的问题落在它可能改变谁、哪些选择或做事方式上；其他主题依照其实际阅读价值选择，不强套商业战略视角。

内部先明确三个问题：最后靠什么留住注意力？要揉进什么已有观点？希望读者带着问题离开，还是带着一个落定的判断离开？据此选择一种主导方式，不默认把所有方式叠加。

- **开放循环**：正文已兑现主要承诺，再用一个具体问题打开新的思考空间。可以是真心想知道答案的问题，也可以是自然的修辞问句；适合引出迁移、适用边界或值得讨论的后果。例如从「这个案例做到了」进一步问「换一个情境，还能做到吗」。新问题必须由正文生长出来，不靠扣住本该交付的答案制造悬念，不用万能的「你怎么看」代替具体问题，不凭空暗示下期会揭晓。
- **闭合循环**：用一句有分量的判断、自然的笑话或回扣开头的收束，让已有观点落定，形成「最后一蘸」的余味。可以有挑衅性，但力度必须符合作者原有立场和口吻，不能为了像感叹号就加重断言、制造对立或硬造金句。闭合不等于复述全文，也不要求真的加感叹号。
- **软 CTA**：轻量邀请读者采取一个行动，如尝试、关注或回应。仅在用户要求，或原稿已有相应行动目标时使用；不默认追加关注、购买、私信或评论要求，不虚构产品、链接与承诺。CTA 不是每篇都需要的结尾。

开放循环可参考两类问题方向，先从正文提取具体对象、行为与尚未解决的影响，再用作者的语气表达：

- **对群体的影响**：「你觉得，这会改变［正文涉及的群体］的［具体处境或选择］吗？」适合正文已经说明变化及可能影响，而影响的范围或方向仍值得讨论时。
- **对读者做法的影响**：「如果是这样，你会调整自己［正文涉及的具体做法］的方式吗？」适合变化与读者已有行为确实相关时。

这些是选题方向，不是每篇必填的句式。不要只换名词机械套用，也不要把「可能影响」写成已经确定的结果。问题应让读者有具体经验、判断或选择可以回应；若正文没建立这种关联，就选别的相关问题或闭合循环。

开放循环也可以把值得讨论或转述的问题放进内容本身：考虑读者可能把它分享给谁、为什么那个人会在意，或哪个具体问题值得带到别处继续讨论。以内容本身提供分享理由，不默认加「转给某某」。这只是传播设计的方向，不意味着加一个问号就能带来病毒传播。

**清楚比形式完整更重要。** 结尾的问题应让人一读就知道在问什么、为什么此刻问。不要为了首尾呼应，把具体矛盾抽象成「你会怎么选择」「未来又会怎样」；若必须额外解释才能懂，就回到原稿中的具体行为与差异。原稿已有有力的疑问或感叹，可以直接收住，无需再加一个开放问题。

两种循环都可能有效，按内容与作者意图选择，不宣称某一种必然带来评论或传播。用户提供的 Messi 视频故事只是讲述者对自身案例的回顾，不能当作本稿传播效果的证明。若原稿的自然收尾已经合适，就保留。

### 6. 交稿前核对

- 改稿中的每个事实、比较和因果是否都能回到原文？没有依据的内容删掉或恢复成原有关系。
- 是否仍像作者本人说话？有没有删掉关键犹豫、改变语气或擅自替作者下更强结论？
- 读者继续读的理由是否更清楚，而不只是句子更夸张？
- 开头能否让读者马上认出具体语境与重要性？熟悉的预期是否有依据？如使用证明与计划，是否真实且与正文对应？
- 新开头能否自然接上未改的正文？是否重复后文、泄漏了刻意保留的信息，或许诺了没有的内容？
- 结尾是否承接作者已有观点？开放循环是否先兑现正文承诺再打开相关问题？闭合循环是否真正收束而没有拔高立场？软 CTA 是否有原稿或用户意图支持？
- 结尾的提问是否一读就懂，有具体对象与矛盾，而不需要另作解释？
- 最后一句还提供什么值得带走的价值？它是否符合读者来读这篇内容的原因？去掉索取互动的话后，结尾本身是否仍成立？
- 原稿已经有效时，保留或只做必要的小改，不制造问题。

## 默认交付

先给 **一版可直接使用的改稿**，不在正文里插入批注、结构标签或加粗标记。保留原有段落风格。

随后用一至三条简短说明指出具体改动：例如把哪条信息提前、拉近了哪两个事实、哪一处从罗列变成了有依据的推进。处理结尾时，简短指出采用哪种收尾、承接了什么观点，以及为何适合。不要只说「更有张力」「更吸引人」。

只有用户要求多个版本，或存在确实有用的两种取舍时才提供备选；默认不要输出十几个套路开头、打分表或长篇理论课。素材不足时仍先交付能完成的最小修改，再提出一个具体补充点。用户只要改稿时省略说明。

## 校准示例

以下均为虚构教学例，不得当成用户的经历。示例展示决策边界，不是固定写法。

**原文**：我本来想把课全部看完再开始写。后来发现课越看越多，我还是一个字没写。所以我昨天只看了一节，就关掉页面写了两百字。写得挺乱的。

**最小修改**：我本来想把课全部看完再开始写。但课越看越多，我还是一个字没写。所以昨天只看了一节，我就关掉页面，写了两百字。写得挺乱的。

保留「写得挺乱的」和作者的语气；预期与现实已有反差，只需要拉近关系。不能改成「我终于悟了：学习才是写作最大的敌人」，那改变了作者的判断。

**原文**：早上去了菜市场，然后买了番茄，然后回家做了面。

**可改**：早上去了菜市场，买了番茄，回家做了面。

这里只能精简。不能编造番茄涨价、没钱吃饭或「这碗面改变了我」。如果用户仍要更强吸引力，可问当天哪个具体细节让其想写下这件事。

**原文**：我发了三篇文章，后来有两个人来问课程。

保留时间关系，不改成「正是这三篇文章，让两个人来问课程」。除非用户提供来源依据，否则询盘原因仍未知。

**选对比对象的例子**：原稿说「我以为节目请到名人才有人听。我们录了十期，播放最多的却是和楼下修车师傅聊的一期。他讲了自己怎么决定哪些活不接。那期录了四十分钟。」

候选中，「预期名人才有人听 → 实际普通嘉宾那期播放最多」由原文直接支持，且适合以嘉宾选择为主旨的开头。「修车师傅 → 会拒绝接活」可能有意思，但原稿没有建立读者认为修车师傅什么活都接的预期，不能擅自声称；「四十分钟」本身也没有对比基线。可以优先前置第一对，并保留拒绝接活的细节作为继续阅读的内容。不杜撰播放数字或把「最多」改成「爆火」。


**结尾选择的例子**：原稿说「我总想等大块时间再写，但等了一周也没动笔。今天午休写了十分钟，写完了一段。对我来说，十分钟也可以是开始。」

- 开放循环可收为「对我来说，十分钟也可以是开始。那还有哪些事，也被我放在了『等有空再说』里？」从已经交付的个人发现打开一个相关问题，不推断所有人都如此。
- 闭合循环可以直接保留「对我来说，十分钟也可以是开始。」它已回应开头等待大块时间的困境，不必升级成「所有拖延都是借口」。

这两种是选法示例，实际交付默认只给最适合的一版；不能因为本节列出三种方式就自动输出三个结尾。
