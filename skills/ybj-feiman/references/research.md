# 设计依据与边界

本 Skill 的轻量研究结论是“条件性答案”：可教代理、自我解释和针对知识关系的检查提供设计依据，但不构成此通用聊天 Skill 学习效果的实证验证。名称中的 Feynman 表示用户选定的费曼学习陪练定位，不意味着以下步骤由费曼提出。

## 1. 可教代理：限制学生知识并让其主动提问

Jin 等，Teach AI How to Code: Using Large Language Models as Teachable Agents for Programming Education，2024 年修订版。

[作者论文](https://arxiv.org/abs/2309.14534)

原始来源摘要已核实。研究在算法学习场景中限制语言模型学生的知识，并让其提出 why/how 问题。论文报告了 40 名算法初学者的组间研究。它支持将“学生已教知识”作为角色约束，也提醒知识过多会降低用户教学动力。

本 Skill 据此要求学生不自动补全解释。研究限定在特定环境与学科，不能直接外推为成年人所有主题均有效；指令也不能真正删除模型知识。

## 2. 自我解释：连接步骤与原理

Chi 等，Self-Explanations: How Students Study and Use Examples in Learning To Solve Problems，1987 年技术报告；相关论文发表于 1989 年。

[ERIC 技术报告记录](https://eric.ed.gov/?id=ED296291)

本轮已核实机构检索摘要，未核对全文。摘要比较了学习者如何把例题步骤与原理连接。设计采用其机制方向：遇到跳步时请用户补出连接，避免只复述名词。

这是对自我解释机制的应用推断；不据此声称某种追问顺序、轮数或所有对话场景的效果已经得到验证。

## 3. Betty’s Brain：以查询和解释检查知识关系

Kinnebrew、Biswas、Sulcer，Modeling and Measuring Self-Regulated Learning in Teachable Agent Environments，2010。

[AAAI 原文](https://cdn.aaai.org/ocs/2270/2270-9453-1-PB.pdf)

原始来源正文已核实。系统让学习者构建因果概念图来教虚拟学生，并通过查询、解释和测验检查教学结果。它为“检查关系和应用表现，而非接受一句懂了”提供设计依据。

研究以小学科学、概念图和结构化工具为环境。自由对话中的复述可能混入模型已有知识，因此学生答对不能充当用户掌握的独立证明。

## 失败模式与经验规则

重点避免：模型利用既有知识补全用户未讲出的内容，再宣称已经学会；这种输出会遮住待解释的前提。

每轮一个问题、连续两次卡住后换方式、总结时至多一个下一步，是初版交互设计，未找到直接验证这些具体阈值的研究。它们应根据真实陪练反馈调整。

事实核对与学生教学状态分开记录。讲得通、事实正确和能迁移是不同判断，任何一项都不能由另一项自动推定。
