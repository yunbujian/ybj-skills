# ybj-skills · 云不见技能合集

用于课程检索、写作修改、学习陪练、语言复盘、公众号排版和 YouTube 中文策展。

本仓库包含 **11 个可安装 Skill**：6 个课程技能，以及费曼学习陪练、写作反差、语言转化、公众号 HTML 排版和 YouTube 策展。

课程技能仅提供规则、课程标题和章节索引，不公开付费课程入口，**不包含课程全文**。使用课程技能时，请已购用户自行提供课程链接或正文；安装不授予课程网站访问权限。其他技能的依赖见下方说明。

## 第一步：安装

在支持安装 Skill 的 AI 工具中，直接发送：

> 帮我安装 https://github.com/yunbujian/ybj-skills 中的全部 Skill。

也可以通过终端安装，需要先有 Node.js 和 npm：

```bash
npx -y skills add yunbujian/ybj-skills -g --all
```

如果安装后没有识别到技能，重新开启一次对话。

## 第二步：提供一次 Free Writes 总入口

把你收到的 **Free Writes 总入口**粘贴给 AI，再说出你想研究的问题：

> 使用 ybj-library。我的 Free Writes 总入口是【粘贴入口地址】。我想研究公开写作，先推荐最相关的三节课，提炼要点并附原文链接。

**在同一段对话里，只需提供一次总入口。** AI 会沿入口查找课程和章节，你不必逐门提供网址。开启新对话后，如果 AI 没有保留入口，再提供一次即可。

请勿把付费课程入口发布到公开平台。

## 第三步：直接提问

提供入口后，就可以继续问：

**找相关内容**

> 课程里有没有讲过怎样获得读者信任？推荐最相关的三节，说明为什么值得读。

**解决写作卡点**

> 我每天写作都像重新开始，课程里有没有讲过怎么接着昨天继续写？

**找一个能开始的练习**

> 我害怕发表后被评价，帮我找相关内容，再给一个今天可以尝试的小练习。

**带着稿件找方法**

> 这篇文章像自说自话，先找能指导修改的课程，再结合原稿提出建议：【粘贴文章】

**进一步查正文**

> 不只查标题，也看看相关正文有没有讨论这个问题。请区分已经核实的内容和目录中的候选线索。

如果 AI 没有调用课程检索功能，在问题前加上“使用 ybj-library”。在 Codex 中也可以写 `$ybj-library`。

## 你会得到什么

AI 会根据问题查找候选课节，读取相关正文后返回：

- **课名与课号**：告诉你去哪里看。
- **核心要点**：提炼与问题相关的内容。
- **推荐理由**：说明这节课能帮助你解决什么。
- **原文链接**：点击即可跳转，继续阅读课程。

想继续深入，可以直接说：“展开第二节”“给我一个练习”或“结合我的情况解释一下”。

## 使用时留意

课程检索需要 AI 工具能够访问网页。无法读取的页面会明确说明，不会把目录标题当成已经核实的课文；必要时，你可以粘贴相关正文继续分析。

一次回答通常按问题读取相关课节，不代表已经搜索全部课程正文。重要内容请点击原文核对，AI 的应用建议也不完全等同于课程原意。

公开安装包不包含付费课程网址。入口由你在使用时提供。

## 工具与环境

- 反差写作、语言转化、费曼陪练：无需额外脚本依赖。
- 公众号排版：随包提供 `templates/styles.md`，需要 AI 工具能够保存 HTML 文件；不自动上传或发布到公众号。
- YouTube 策展：需要网页读取和文件保存能力；随包脚本需要 Python 3.10+。获取视频元数据与字幕还需要在同一 Python 环境安装 `yt-dlp`（`python3 -m pip install yt-dlp`）。音频转写需另备转写工具，本包不自带模型。字幕获取可能受视频可用性和网络条件影响。
- YouTube 策展优先使用用户指定的保存目录；未指定时保存到当前工作目录的 `策展内容库/<中文标题>/`。仅有链接时，全文翻译和引文范围遵守宿主工具的规则。
